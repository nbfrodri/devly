**PATH** es una [variable de entorno](/articulos/variables-de-entorno-y-secretos/): un valor que los programas reciben al iniciarse. Contiene directorios que ciertas funciones y herramientas, incluida la [shell](/articulos/terminal-y-shell/), consultan para localizar ejecutables por su nombre.

En sistemas de tipo Unix se separan con `:`. La lista se recorre en orden al buscar un nombre sin `/`. Escribir `./programa` o `/usr/bin/programa` ya proporciona una ruta y evita esa búsqueda.

## Dos copias, un orden

Este modelo representa solo la búsqueda entre rutas absolutas de ejecutables ya comprobados. No examina archivos ni permisos reales:

```js
const ruta = "/home/ana/.local/bin:/usr/local/bin:/usr/bin:/bin";
const instalados = new Set(["/usr/bin/node", "/usr/local/bin/node", "/usr/bin/git"]);

const buscar = (programa) =>
	ruta.split(":").map((dir) => `${dir}/${programa}`).find((c) => instalados.has(c)) ?? "no encontrado";

console.log(buscar("node")); // "/usr/local/bin/node"
console.log(buscar("python")); // "no encontrado"
```

La primera carpeta no aporta `node`; la segunda sí, así que gana frente a `/usr/bin/node`. En una búsqueda real también importan permisos, tipo de archivo y posibilidad de ejecutarlo.

## Saber qué interpreta tu shell

En Bash puedes consultar el valor y la resolución de una orden:

```bash
printf '%s\n' "$PATH"
command -v sh
type cd
```

Las dos primeras salidas dependen del entorno. La tercera identifica `cd` como una orden interna de Bash. Alias y funciones también pueden intervenir antes de buscar un archivo en PATH; `which` no describe necesariamente todas esas reglas. Bash puede recordar rutas resueltas; `hash -r` vacía esa memoria cuando necesitas repetir la búsqueda.

Un mensaje de orden no encontrada puede deberse a un nombre incorrecto, una instalación ausente o un directorio fuera de PATH. Tener el archivo localizado tampoco demuestra que sus dependencias estén disponibles.

## Cambiar el alcance correcto

Un `export PATH=...` afecta a esa shell y a los programas que inicie después; no actualiza procesos que ya estaban ejecutándose. Los archivos de inicio dependen de la shell y del tipo de sesión: `.bashrc` se lee normalmente en Bash interactivo sin inicio de sesión, pero no configura por sí solo todos los servicios y guiones.

Añadir `.` o una entrada vacía puede incluir el directorio actual en la búsqueda. Si otra persona controla esa carpeta, podría introducir una orden con un nombre esperado. Conserva un orden deliberado y directorios apropiados para el contexto.

## Lo esencial

- PATH sirve para buscar ejecutables por nombre; una ruta con `/` sigue otro recorrido.
- El orden importa, pero la shell también resuelve alias, funciones y órdenes internas.
- El valor pertenece al entorno de cada proceso; cambiarlo en una sesión no cambia todas.
