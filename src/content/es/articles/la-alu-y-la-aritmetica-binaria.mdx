La **ALU**, unidad aritmético-lógica, realiza operaciones enteras dentro del [procesador](/articulos/como-funciona-un-procesador/): suma, resta, compara y combina bits. Recibe operandos y una selección de operación; entrega un resultado y puede producir señales que describen ese resultado.

Estudiaremos un modelo de ocho bits construido con [puertas lógicas](/articulos/puertas-logicas/). Sus bits representan valores de 0 a 255 sin signo, o de −128 a 127 en [complemento a dos](/articulos/complemento-a-dos/). La misma secuencia de bits puede tener esas dos interpretaciones.

## Sumar una columna

Un **sumador completo** recibe los dos bits de una columna y el acarreo de la anterior. Devuelve el bit de suma y el acarreo siguiente. En la columna con entradas 1, 1 y acarreo 1, el total es tres: `11` en binario. Sale un 1 y se lleva otro 1.

Al encadenar ocho columnas obtenemos este sumador. Acepta únicamente enteros entre 0 y 255; JavaScript lo simula, no reproduce sus tiempos eléctricos:

```js
function sumadorCompleto(a, b, entrada) {
	return {
		suma: a ^ b ^ entrada,
		acarreo: (a & b) | (entrada & (a ^ b)),
	};
}

function sumar8(x, y) {
	if (![x, y].every((n) => Number.isInteger(n) && n >= 0 && n <= 255)) {
		throw new RangeError("Se requieren dos enteros de 0 a 255");
	}
	let acarreo = 0;
	let resultado = 0;
	for (let i = 0; i < 8; i++) {
		const columna = sumadorCompleto((x >> i) & 1, (y >> i) & 1, acarreo);
		resultado |= columna.suma << i;
		acarreo = columna.acarreo;
	}
	const desbordamientoConSigno = Number(((~(x ^ y) & (x ^ resultado)) & 128) !== 0);
	return { resultado, acarreo, desbordamientoConSigno };
}

for (const [a, b] of [[100, 27], [200, 100], [127, 1]]) {
	const r = sumar8(a, b);
	console.log(r.resultado, r.acarreo, r.desbordamientoConSigno);
}
// 127 0 0
// 44 1 0
// 128 0 1
```

La fórmula final detecta operandos del mismo signo cuyo resultado tiene el signo contrario. El bit de peso 128 es el bit de signo; la máscara descarta los demás.

## Acarreo y desbordamiento no son lo mismo

En **200 + 100 sin signo**, 300 supera 255: los ocho bits bajos conservan 44 y el acarreo vale 1. Interpretados con signo, esos mismos operandos son −56 y 100; su suma, 44, sí cabe.

En **127 + 1 con signo**, el resultado matemático es 128, fuera del intervalo permitido. El patrón obtenido, `10000000`, se interpreta como −128. Hay desbordamiento con signo aunque no haya acarreo de salida.

## Restar reutilizando la suma

Para calcular A − B en ocho bits podemos sumar A, los bits invertidos de B y un acarreo inicial de 1. Se conservan los ocho bits bajos:

```js
const opuesto8 = (x) => ((~x & 255) + 1) & 255;
const restar8 = (a, b) => (a + opuesto8(b)) & 255;
const conSigno8 = (n) => n < 128 ? n : n - 256;

console.log(opuesto8(5)); // 251
console.log(restar8(20, 5)); // 15
console.log(conSigno8(restar8(127, 255))); // -128
```

Estas funciones reciben patrones de ocho bits, enteros de 0 a 255. El patrón 251 representa −5; 20 + 251 deja 15 al descartar el acarreo. En la última línea, 255 representa −1: **127 − (−1)** desborda. El valor negativo almacenado no implica que 127 sea menor que −1.

Para comparar con signo mediante una resta se debe combinar su indicador negativo **N** con el desbordamiento **V**: A es menor que B cuando `N XOR V` vale 1. Aquí N = 1 y V = 1, por lo que da 0. Igualdad se comprueba con el resultado cero. Las comparaciones sin signo requieren otra interpretación; además, no todas las arquitecturas exponen registros de indicadores.

## Multiplicar desplazando y sumando

Cada bit del multiplicador decide si se añade una copia desplazada del multiplicando. Para 13 × 11, el 11 binario es `1011`: se suman 13, 26 y 104; la posición de 52 no participa. El resultado es 143.

```js
function multiplicar8(a, b) {
	if (![a, b].every((n) => Number.isInteger(n) && n >= 0 && n <= 255)) {
		throw new RangeError("Se requieren dos enteros de 0 a 255");
	}
	let resultado = 0;
	while (b > 0) {
		if (b & 1) resultado += a;
		a <<= 1;
		b >>= 1;
	}
	return resultado;
}

console.log(multiplicar8(13, 11)); // 143
console.log(multiplicar8(255, 255)); // 65025
```

El producto completo puede necesitar dieciséis bits. Los límites de entrada mantienen los desplazamientos dentro de los enteros de 32 bits que usa JavaScript para estas operaciones; aumentar arbitrariamente el tamaño rompería el modelo.

## Del modelo a una implementación

En el sumador encadenado, el acarreo puede recorrer todas las columnas. Diseños con anticipación o árboles de acarreo reducen esa dependencia usando más lógica. Los multiplicadores pueden combinar productos parciales en paralelo o repartir trabajo entre ciclos: no hay una implementación universal.

Una ALU combinacional no guarda su resultado; lo capturan [registros](/articulos/circuitos-secuenciales-y-biestables/). Las unidades reales pueden estar segmentadas y repartir operaciones entre varios circuitos. AND, OR y XOR actúan sobre cada posición sin propagar acarreo, pero sus latencias concretas dependen del diseño.

El programa también importa: un lenguaje puede descartar bits sobrantes, detectar el desbordamiento o prohibirlo. Un desplazamiento no sustituye cualquier división con signo, por las reglas de redondeo. La [coma flotante](/articulos/coma-flotante/) requiere otro tratamiento de representación y operaciones.

## Lo esencial

- La ALU combina operandos según la operación seleccionada.
- Un sumador completo maneja dos bits y un acarreo; varios permiten sumar una palabra.
- Acarreo y desbordamiento con signo responden a interpretaciones distintas.
- El tamaño, los indicadores y las reglas del lenguaje condicionan el significado del resultado.
