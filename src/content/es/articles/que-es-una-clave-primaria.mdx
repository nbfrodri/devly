Una **clave primaria** es la columna, o el conjunto de columnas, elegida para **identificar de forma única** cada fila de una tabla en una [base de datos relacional](/articulos/que-es-una-base-de-datos/). No debe repetirse ni contener NULL. Eso es distinto de un texto vacío, que necesitaría otra restricción si quieres prohibirlo.

## Un ejemplo

Ejecuta este bloque en SQLite:

```sql
CREATE TABLE clientes (
	id INTEGER PRIMARY KEY,
	correo TEXT UNIQUE NOT NULL,
	nombre TEXT NOT NULL
);
INSERT INTO clientes VALUES (1, 'ana@ejemplo.com', 'Ana');
SELECT id, nombre FROM clientes;
```

La consulta devuelve `1, Ana`. `id` es la clave primaria y SQLite rechaza identificadores repetidos. Su forma especial `INTEGER PRIMARY KEY` genera un identificador si omites el valor o insertas NULL: no almacena ese NULL como clave. En otras claves de SQLite conviene declarar también `NOT NULL`, porque sus tablas ordinarias conservan excepciones históricas a esa regla.

## Para qué sirve

- **Identificar** una fila sin ambigüedad: actualizar o borrar exactamente esa.
- **Relacionar** tablas: otras tablas guardan ese valor como **clave foránea**. Cada pedido guarda el `id` de su cliente.

## Natural o artificial

- **Natural**: un dato que ya es único en el mundo real, como un número de documento.
- **Artificial**: un número o un identificador generado sin significado, como `id`.

Una clave artificial desacopla la identidad de datos que pueden cambiar, como el correo. Tampoco vuelve únicos esos datos por sí sola: necesitas conservar sus restricciones de dominio.

## Compuesta

A veces la clave son varias columnas juntas. La pareja `(pedido_id, producto_id)` sirve si un producto solo puede aparecer una vez en cada pedido; si admites varias líneas del mismo producto, necesitas otro identificador de línea.

## Otras formas de identificar

Una tabla puede tener varias [claves candidatas](/articulos/que-es-una-clave-candidata/). La primaria es la elegida como identificador principal; las demás siguen necesitando sus restricciones de unicidad y ausencia de NULL si deben identificar cada fila.

## Con qué no confundirla

- **Clave foránea**: referencia una clave primaria o única admitida por el motor, incluso de la misma tabla. Puede repetirse si no se impone otra restricción.
- **Columna única**: también impide repetidos, como `correo` en el ejemplo, pero una tabla puede tener varias. Clave primaria solo hay una.
