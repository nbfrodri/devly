Un **objeto** es una estructura que agrupa datos relacionados bajo un mismo nombre. Cada dato es una **propiedad**, con un nombre y un valor. Si el objeto incluye funciones que trabajan con sus datos, esas funciones se llaman **métodos**.

## Un ejemplo

```js
const libro = {
	titulo: "Rayuela",
	paginas: 600,
	leidas: 150,
	progreso() {
		return Math.round((this.leidas / this.paginas) * 100);
	},
};

console.log(libro.titulo); // "Rayuela"
console.log(libro.progreso()); // 25
```

`titulo`, `paginas` y `leidas` son propiedades. `progreso` es un método: usa los datos del propio objeto, a los que accede con `this`.

## Por qué son útiles

Sin objetos, un libro serían tres variables sueltas: `tituloLibro`, `paginasLibro`, `leidasLibro`. Con varios libros, el desorden crece. Un objeto mantiene juntos los datos que van juntos.

## Con qué no confundirlo

- **Clase.** Una [clase](/articulos/que-es-una-clase/) es el molde; un objeto, una pieza concreta hecha con él. Todos los libros comparten estructura; cada uno tiene sus valores.
- **[JSON](/articulos/formatos-de-datos-json-csv-xml/).** Se parece mucho a un objeto de JavaScript, pero es solo texto: un formato para guardar o transmitir datos, sin métodos.

En la [programación orientada a objetos](/articulos/programacion-orientada-a-objetos/), los objetos son la unidad central con la que se organiza un programa.

La [igualdad y la identidad](/articulos/igualdad-e-identidad/) responden preguntas diferentes: dos objetos con los mismos campos pueden ser instancias distintas.
