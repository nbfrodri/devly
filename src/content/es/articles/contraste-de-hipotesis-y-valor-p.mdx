Un **contraste de hipótesis** compara los datos observados con una hipótesis y un modelo de cómo se obtendrían esos datos. El **valor p** es la probabilidad, bajo ese modelo, de un resultado al menos tan extremo como el observado según un criterio elegido. Ayuda a evaluar incompatibilidad con el modelo; no decide por sí solo si hay una causa real.

## El razonamiento

Se lanza una moneda 100 veces de forma independiente y salen 60 caras. ¿Son estos datos incompatibles con una probabilidad de cara de 0,5?

1. Se plantea la **hipótesis nula**: la probabilidad de cara es 0,5. Aquí representa ausencia de sesgo; en otros contrastes la hipótesis puede especificar otro valor.
2. Se calcula lo raro que sería un resultado **al menos tan extremo** como el observado **si la hipótesis nula fuera cierta**. Ese es el **valor p**.
3. Si es muy raro, se **rechaza** la hipótesis nula. Si no, no hay pruebas suficientes para rechazarla.

```js
function combinaciones(n, k) {
	let r = 1;
	for (let i = 1; i <= k; i++) r = (r * (n - k + i)) / i;
	return r;
}

let colaSuperior = 0;
for (let caras = 60; caras <= 100; caras++) {
	colaSuperior += combinaciones(100, caras) * 0.5 ** 100;
}

const valorP = 2 * colaSuperior;
console.log(valorP.toFixed(4)); // "0.0569"
```

Con una moneda justa, obtener 60 caras o más, o 40 o menos, ocurre un 5,7 % de las veces. Se multiplica por dos porque se buscaba un desvío en cualquier sentido.

## El umbral

Antes de mirar los datos se fija un **nivel de significación**, α, por ejemplo 0,05. Se rechaza cuando el valor p queda por debajo del umbral establecido. Bajo los supuestos de un contraste válido, α controla la probabilidad de rechazar una hipótesis nula verdadera. En un contraste exacto discreto, como este recuento de caras, la tasa puede ser menor que el nivel nominal: los resultados posibles dan saltos.

Aquí, 0,0569 es mayor que 0,05: no se puede afirmar que la moneda esté trucada. Eso **no** demuestra que sea justa; solo que estos datos no bastan para decir lo contrario.

## Dos formas de equivocarse

| | La hipótesis nula es cierta | La hipótesis nula es falsa |
| --- | --- | --- |
| Se rechaza | Error de tipo I: falso positivo, controlado por α | Acierto |
| No se rechaza | Acierto | Error de tipo II: falso negativo |

Bajar α, manteniendo muestra y procedimiento, suele reducir falsos positivos a costa de detectar menos efectos. Con más observaciones independientes, un contraste adecuado puede ganar **potencia** —probabilidad de rechazar una nula falsa para un efecto concreto— manteniendo el mismo α. Aumentar la muestra no reduce automáticamente ese nivel de falsos positivos.

## Lo que el valor p no es

En 2016, la Asociación Estadounidense de Estadística publicó una declaración con seis principios sobre el valor p, por el mal uso tan extendido. Entre ellos:

- El valor p **no** mide la probabilidad de que la hipótesis estudiada sea cierta, ni la probabilidad de que los datos se deban solo al azar.
- Las decisiones científicas o de negocio **no** deberían basarse solo en si el valor p supera un umbral.
- Un valor p no mide el **tamaño** del efecto ni su importancia. Con muestras enormes, una diferencia minúscula e irrelevante puede dar un valor p diminuto.

Por eso conviene acompañarlo de una estimación del efecto y un [intervalo de confianza](/articulos/intervalos-de-confianza/) que exprese su incertidumbre, junto con los supuestos y el contexto del estudio.

## La trampa de buscar hasta encontrar

Si 20 hipótesis nulas son verdaderas y cada prueba tiene una tasa de error de 0,05, el número esperado de falsos positivos es `20 × 0,05 = 1`. No significa que aparezca exactamente uno. Si además las pruebas son independientes, la probabilidad de al menos uno es `1 - 0,95²⁰ ≈ 0,642`, no el 100 %. La dependencia cambia esta última cuenta.

Probar muchas hipótesis y publicar solo la que salió favorable es una forma de *p-hacking* o «dragado de datos». También se altera el error si se mira un contraste de muestra fija cada día y se detiene cuando parece favorable. Para varias comparaciones o análisis secuenciales hacen falta procedimientos diseñados para ello, como se explica en [pruebas A/B](/articulos/pruebas-a-b/).

## Lo esencial

- Un contraste compara datos con una hipótesis y sus supuestos.
- El valor p mide la probabilidad de resultados al menos tan extremos bajo ese modelo.
- Un valor p bajo no dice que la hipótesis sea cierta ni lo grande que es el efecto.
- Seleccionar solo las pruebas favorables aumenta el riesgo de conclusiones falsas y oculta cuántas oportunidades de error hubo.
