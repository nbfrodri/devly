La **sintaxis** de un lenguaje de programación es el conjunto de reglas que determina cómo se escribe un programa válido: qué palabras y símbolos existen y en qué orden pueden aparecer. Es la gramática del lenguaje.

## Un ejemplo

En JavaScript, un condicional se escribe así:

```javascript
if (edad >= 18) {
	console.log("Mayor de edad");
}
```

Los paréntesis alrededor de la condición y las llaves alrededor del bloque son sintaxis. En Python, la misma idea se escribe sin paréntesis ni llaves, con dos puntos y sangría.

Si se incumple una regla, el programa ni siquiera empieza a ejecutarse: el [compilador o el intérprete](/articulos/compilador-e-interprete/) lo rechaza con un **error de sintaxis**.

```js
try {
	new Function("let = ;");
} catch (error) {
	console.log(error.name); // "SyntaxError"
}
```

## Sintaxis y semántica

Con qué no confundirla:

- La **sintaxis** dice si un programa está **bien escrito**.
- La **semántica** dice **qué significa**, qué hace al ejecutarse.

Un programa puede tener una sintaxis perfecta y hacer algo absurdo: sumar donde había que restar. La sintaxis la comprueba la máquina antes de ejecutar; la semántica, solo las [pruebas](/articulos/pruebas-de-software/) y quien lee el código.

## Azúcar sintáctico

Se llama así a una forma más cómoda de escribir algo que ya se podía expresar de otro modo. Las funciones flecha de JavaScript, `(x) => x * 2`, son en buena parte azúcar sintáctico sobre las funciones normales.
