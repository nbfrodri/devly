El **aprendizaje automático** (*machine learning*) es una forma de construir programas en la que un algoritmo ajusta un modelo a partir de datos. Quien lo diseña sigue eligiendo datos, representación, objetivo y procedimiento de aprendizaje; no escribe a mano cada regla de decisión. Es la técnica que hay detrás de la mayor parte de lo que hoy se llama inteligencia artificial, incluidos los [modelos de lenguaje](/articulos/modelos-de-lenguaje/).

## Qué problema resuelve

Programar consiste normalmente en escribir reglas. Funciona cuando sabes describirlas: calcular un impuesto, ordenar una lista.

Hay tareas para las que nadie sabe escribir las reglas. ¿Qué instrucciones exactas distinguen la foto de un gato de la de un perro? Las personas lo hacemos sin esfuerzo, pero no sabemos explicarlo paso a paso.

El aprendizaje **supervisado**, en el que los ejemplos incluyen respuestas conocidas, da la vuelta al planteamiento:

| | Entrada | Resultado |
| --- | --- | --- |
| Programación tradicional | Datos y reglas | Respuestas |
| Aprendizaje supervisado | Datos y respuestas conocidas | Modelo ajustado |

En lugar de reglas, reúnes muchas fotos ya etiquetadas como "gato" o "perro" y dejas que un algoritmo encuentre qué las diferencia.

## Las piezas

- **Datos de entrenamiento**: los ejemplos de los que se aprende.
- **Características**: los datos de entrada de cada ejemplo. En una vivienda, los metros y el número de habitaciones.
- **Etiqueta**: la respuesta correcta de cada ejemplo. En la vivienda, su precio.
- **Modelo**: el resultado del aprendizaje. Es una [función](/articulos/funciones/) con números ajustables, llamados **parámetros**, que convierte unas características en una predicción.

## Entrenar

En el caso supervisado, **entrenar** es ajustar el modelo según un objetivo que compara predicciones y etiquetas. Muchos métodos lo hacen mediante un proceso repetitivo:

1. El modelo predice con los parámetros que tiene.
2. Se mide cuánto se ha equivocado.
3. Se corrigen un poco los parámetros para reducir el error.
4. Se repite muchas veces.

Un ejemplo mínimo: quieres predecir `y` a partir de `x` y supones que la relación es `y = peso * x`. El único parámetro es `peso`.

```js
const ejemplos = [
	{ x: 1, y: 2 },
	{ x: 2, y: 4 },
	{ x: 3, y: 6 },
];

let sumaXY = 0;
let sumaXX = 0;

for (const { x, y } of ejemplos) {
	sumaXY = sumaXY + x * y;
	sumaXX = sumaXX + x * x;
}

const peso = sumaXY / sumaXX;
console.log(peso); // 2

const predecir = (x) => peso * x;
console.log(predecir(4)); // 8
```

Hemos elegido la familia de reglas `y = peso * x`, pero no el valor del peso. El programa obtiene `2` porque la suma de productos es `28` y la suma de cuadrados es `14`. Esa fórmula minimiza la suma de errores al cuadrado en esta familia, siempre que el denominador no sea cero. Después calcula `2 * 4 = 8`: es una predicción, no una prueba de que toda entrada futura siga la misma relación.

Aquí el mejor valor se calcula con una fórmula directa. También hay modelos útiles pequeños y métodos sin ajuste iterativo. Algunas redes neuronales, en cambio, tienen millones de parámetros y necesitan muchas actualizaciones.

## Entrenar no es usar

Hay dos fases distintas:

- **Entrenamiento**: se ajusta el modelo con los datos. Puede ser costoso; el coste total también depende de cuántas inferencias se hagan.
- **Inferencia**: se usa el modelo ya entrenado para predecir sobre datos nuevos.

## Tres formas de aprender

- **Supervisado**: los ejemplos llevan la respuesta correcta. Sirve para predecir un número (un precio) o una categoría (correo deseado o no): es la diferencia entre [regresión y clasificación](/articulos/clasificacion-y-regresion/).
- **No supervisado**: los ejemplos no llevan respuesta. El algoritmo busca estructura por su cuenta, por ejemplo grupos de clientes parecidos.
- **[Por refuerzo](/articulos/aprendizaje-por-refuerzo/)**: un programa prueba acciones y recibe recompensas o penalizaciones. Aprende qué le conviene a base de intentos.

## Aprender no es memorizar

Un modelo puede acertar todos los ejemplos de entrenamiento y fallar con datos nuevos. Ocurre cuando ha memorizado los ejemplos en lugar de captar el patrón general. Se llama [**sobreajuste**](/articulos/sobreajuste-y-subajuste/).

Para estimar cómo generaliza se evalúa con datos separados del ajuste. Un conjunto de **validación** ayuda a elegir entre modelos; el **conjunto de prueba** se reserva para la evaluación final. Si se toman decisiones repetidamente mirando el resultado de prueba, ese conjunto deja de ser una comprobación independiente.

## Sus límites

Un modelo solo conoce sus datos. Si son escasos, erróneos o no representan bien la realidad, sus predicciones heredarán esos defectos. Entender los datos antes de usarlos empieza por resumirlos con medidas como la [media, la mediana y la desviación típica](/articulos/media-mediana-y-desviacion/). Además predice a partir de patrones estadísticos: puede dar una respuesta equivocada con total seguridad.

## Errores comunes

- **Creer que aprender elimina las decisiones humanas.** Elegir qué datos, modelo y objetivo usar condiciona el resultado.
- **Confundir acertar tres ejemplos con descubrir una ley.** Distintas relaciones pueden coincidir en los datos observados y divergir fuera de ellos.
- **Presentar el acierto de entrenamiento como rendimiento futuro.** El modelo puede ajustarse a peculiaridades de esos datos; hace falta una evaluación separada y representativa.

## Lo esencial

- En el aprendizaje automático un algoritmo ajusta un modelo a partir de datos y de un objetivo elegido.
- Un modelo es una función con parámetros que se ajustan durante el entrenamiento.
- Entrenar ajusta el modelo; inferir es usarlo.
- Un modelo es bueno si acierta con datos que no ha visto, no si memoriza los de entrenamiento.

Uno de los tipos de modelo más usados es la [red neuronal](/articulos/que-es-una-red-neuronal/).
