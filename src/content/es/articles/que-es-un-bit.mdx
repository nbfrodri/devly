Un **bit** es la unidad mínima de información: un valor que solo puede ser `0` o `1`. Todo lo que guarda o procesa un ordenador, sea un texto, una foto o un programa, está hecho de bits.

La palabra viene de *binary digit*, dígito binario.

## Por qué solo dos valores

Un ordenador está hecho de circuitos electrónicos. Lo más sencillo y fiable que puede hacer un circuito es distinguir entre dos estados: hay tensión eléctrica o no la hay. A uno se le llama `1` y al otro `0`.

Podría haberse diseñado para distinguir diez niveles de tensión y trabajar con los dígitos del 0 al 9. Pero cuantos más niveles, más fácil es que una pequeña interferencia haga confundir uno con el vecino. Con dos niveles muy separados, el margen de error es enorme. Esa fiabilidad es la razón de que toda la informática se apoye en el sistema binario.

## Qué puede representar un bit

Un bit distingue entre dos posibilidades, las que sean: sí o no, encendido o apagado, verdadero o falso. Qué significa cada valor depende de quien lo interprete.

Dos posibilidades son pocas. Para representar más, se juntan varios bits.

## Juntar bits

Con dos bits hay cuatro combinaciones: `00`, `01`, `10` y `11`. Con tres, ocho. Cada bit que añades duplica las combinaciones, porque todo lo anterior puede ir ahora precedido de un 0 o de un 1.

| Bits | Combinaciones |
| --- | --- |
| 1 | 2 |
| 2 | 4 |
| 3 | 8 |
| 4 | 16 |
| 8 | 256 |
| 16 | 65 536 |

La regla general: con `n` bits se pueden representar 2 elevado a `n` cosas distintas.

```js
console.log(2 ** 8); // 256
console.log(2 ** 16); // 65536
```

## El byte

Un grupo de 8 bits se llama **byte**. Es la unidad con la que se miden los archivos y la memoria. Con un byte se pueden representar 256 valores distintos, del 0 al 255.

Los tamaños grandes se expresan con prefijos:

| Unidad | Equivale a |
| --- | --- |
| 1 kilobyte (kB) | 1000 bytes |
| 1 megabyte (MB) | 1000 kilobytes |
| 1 gigabyte (GB) | 1000 megabytes |
| 1 terabyte (TB) | 1000 gigabytes |

Verás también esas mismas palabras usadas con saltos de 1024 en lugar de 1000, porque 1024 es una potencia de 2 (2 elevado a 10). Para esos valores existen nombres propios, como kibibyte (KiB) y mebibyte (MiB), aunque en la práctica se mezclan. Por eso un disco de "500 GB" aparece con menos capacidad en algunos sistemas.

## Números en binario

El sistema decimal usa diez dígitos, y cada posición vale diez veces más que la de su derecha: unidades, decenas, centenas.

El **sistema binario** usa dos dígitos, y cada posición vale el doble que la de su derecha: 1, 2, 4, 8, 16...

Para leer un número binario, sumas el valor de las posiciones que tienen un 1. Por ejemplo, `1101`:

| Posición vale | 8 | 4 | 2 | 1 |
| --- | --- | --- | --- | --- |
| Dígito | 1 | 1 | 0 | 1 |

8 + 4 + 1 = 13.

Puedes comprobarlo en JavaScript:

```js
console.log(parseInt("1101", 2)); // 13
console.log((13).toString(2)); // "1101"
```

`parseInt` con un 2 interpreta el texto como binario. `toString(2)` hace el camino contrario.

Para escribir valores binarios de forma más corta se usa el [sistema hexadecimal](/articulos/sistema-hexadecimal/), y los números negativos se guardan en [complemento a dos](/articulos/complemento-a-dos/).

## Todo lo demás también son números

Si los bits sirven para escribir números, cualquier cosa que pueda convertirse en números puede guardarse en bits.

- **Texto**: a cada carácter se le asigna un número. La letra A mayúscula es el 65. El sistema completo se explica en [codificación de caracteres](/articulos/codificacion-de-caracteres/).
- **Imágenes**: una imagen es una cuadrícula de puntos, y el color de cada punto son tres números: cuánto rojo, cuánto verde y cuánto azul.
- **Sonido**: se mide la onda miles de veces por segundo y se guarda cada medida como un número.

```js
console.log("A".charCodeAt(0)); // 65
console.log((65).toString(2)); // "1000001"
```

Los mismos bits pueden ser el número 65 o la letra A. Lo que decide cuál es el [tipo de dato](/articulos/tipos-de-datos/) con el que el programa los interpreta.

## Lo esencial

- Un bit es un valor que solo puede ser 0 o 1.
- Con `n` bits hay 2 elevado a `n` combinaciones.
- 8 bits forman un byte.
- Números, texto, imágenes y sonido se guardan como números escritos en binario.
