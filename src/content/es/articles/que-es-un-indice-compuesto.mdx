Un **índice compuesto**, o multicolumna, es un [índice](/articulos/indices-de-bases-de-datos/) que incluye **varias columnas**. En un árbol B se ordenan primero por la primera y, en caso de empate, por la segunda, y así sucesivamente.

## Un ejemplo

Ejecuta este bloque en SQLite:

```sql
CREATE TABLE clientes (id INTEGER PRIMARY KEY, apellido TEXT, nombre TEXT);
INSERT INTO clientes VALUES (1, 'García', 'Ana'), (2, 'García', 'Luis'), (3, 'Ruiz', 'Ana');
CREATE INDEX idx_apellido_nombre ON clientes (apellido, nombre);
SELECT id FROM clientes WHERE apellido = 'García' AND nombre = 'Ana';
```

La consulta devuelve `1`. El índice se parece a una guía telefónica: apellido y, dentro de cada apellido, nombre. El optimizador decide si utilizarlo; con tres filas recorrer la tabla también puede ser barato.

## El orden de las columnas importa

Con ese índice:

| Consulta | ¿Qué puede localizar directamente? |
| --- | --- |
| `WHERE apellido = 'García'` | El grupo del apellido |
| `WHERE apellido = 'García' AND nombre = 'Ana'` | El intervalo de esa pareja |
| `WHERE nombre = 'Ana'` | Las coincidencias están repartidas entre apellidos |

Es la misma razón por la que una guía telefónica no ayuda a encontrar a todas las personas que se llaman Ana: están repartidas por toda la guía. El índice sirve para la columna inicial, o para las iniciales en orden.

Las columnas posteriores también pueden filtrar entradas durante un recorrido. PostgreSQL documenta además *skip scan*: repetir búsquedas por los grupos de una columna anterior cuando su cantidad lo hace rentable. Comprueba el plan de tu motor y versión.

El orden se elige según consultas, igualdades, rangos y ordenaciones; poner siempre primero la columna con más valores distintos no es una regla suficiente.

## Cuándo usarlo

- Cuando las consultas filtran a menudo por varias columnas juntas.
- Cuando se filtra por una y se ordena por otra: `WHERE cliente_id = 42 ORDER BY fecha`.

## Con qué no confundirlo

Dos índices de una columna cada uno no equivalen a uno compuesto. Y un índice compuesto no sustituye a todos los de sus columnas por separado. Como cualquier índice, acelera las lecturas y ralentiza un poco las escrituras.
