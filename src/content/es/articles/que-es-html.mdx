**HTML** (*HyperText Markup Language*, lenguaje de marcado de hipertexto) describe el contenido y la estructura de una página web. Indica qué fragmentos son encabezados, párrafos, enlaces o controles que el navegador, el programa con el que visitas páginas, debe interpretar.

## Qué problema resuelve

Un texto plano puede decir «Biblioteca, horario, de 9 a 18», pero no señala qué parte es el título, qué horario pertenece a qué sección ni dónde hay un enlace. Un **lenguaje de marcado** añade esas indicaciones mediante etiquetas. El **hipertexto** conecta documentos o partes de un documento mediante enlaces.

HTML no es un lenguaje de programación de propósito general: no se usa para escribir algoritmos con bucles como JavaScript. Eso no significa que una página HTML sea inmóvil. Los enlaces navegan, los formularios envían datos y algunos controles se abren o cierran sin que escribas JavaScript.

[CSS](/articulos/que-es-css/) define la presentación; JavaScript permite programar comportamiento adicional y modificar la representación de la página en memoria, el [DOM](/articulos/el-dom/).

## Elementos, etiquetas y atributos

Un **elemento** es una pieza del documento. Este párrafo contiene otro elemento que marca información importante:

```html
<p>Hoy cerramos a las <strong>18:00</strong>.</p>
```

`<p>` es una **etiqueta de apertura** y `</p>`, una **etiqueta de cierre**. El elemento incluye esas etiquetas y su contenido. **Anidar** consiste en colocar un elemento dentro de otro: aquí `strong` se abre después de `p` y se cierra antes.

Los **atributos** añaden información dentro de la etiqueta de apertura. En `<a href="#horario">Ver horario</a>`, `href` indica el destino. `#horario` apunta a un elemento del mismo documento cuyo atributo `id` vale `horario`. Ese identificador debe ser único en la página.

Muchos atributos usan nombre y valor; escribir el valor entre comillas evita ambigüedades. Los **atributos booleanos** expresan una condición por su presencia: `<button disabled>Reservar</button>` crea un botón desactivado. Para activarlo se retira `disabled`; escribir `disabled="false"` no lo activa.

Algunos tipos, como `img`, `br` y `meta`, son **elementos vacíos**, o *void*: no admiten contenido hijo ni etiqueta de cierre. Es una regla de esos tipos, no una consecuencia de dejarlos sin texto. Un párrafo vacío sigue pudiendo escribirse `<p></p>`.

## Una página completa

Copia este documento en un archivo de texto llamado `index.html`, guárdalo con [codificación UTF-8](/articulos/codificacion-de-caracteres/) y ábrelo en el navegador. No necesita instalar un servidor ni descargar imágenes.

```html
<!doctype html>
<html lang="es">
	<head>
		<meta charset="utf-8">
		<meta name="viewport" content="width=device-width, initial-scale=1">
		<title>Biblioteca del barrio</title>
	</head>
	<body>
		<main>
			<h1>Biblioteca del barrio</h1>
			<p><a href="#horario">Ver horario</a></p>
			<section id="horario">
				<h2>Horario</h2>
				<p>De lunes a viernes, de 9:00 a 18:00.</p>
				<p><strong>El sábado cerramos.</strong></p>
			</section>
			<details>
				<summary>Cómo llegar</summary>
				<p>La entrada está en la calle del Parque, 12.</p>
			</details>
		</main>
	</body>
</html>
```

Sigue el resultado paso a paso:

1. `<!doctype html>` hace que el navegador use el modo estándar de presentación. `html` envuelve el documento y `lang="es"` declara su idioma.
2. `head` reúne información sobre la página. `charset` indica cómo interpretar los caracteres; `viewport` ajusta el área de presentación al dispositivo móvil. `title` da nombre a la pestaña.
3. `body` contiene el contenido de la página. `main` identifica su parte principal, `h1` el encabezado principal y `h2` una sección subordinada. No cambies el nivel de encabezado para cambiar su tamaño.
4. Al activar «Ver horario», el navegador señala el destino `#horario` y se desplaza si hace falta. Como esta página es corta, puede caber entera: el destino cambia igualmente.
5. Al activar «Cómo llegar», `details` muestra el párrafo que estaba plegado. `summary` es el control que lo abre y cierra, también con teclado.

La distinción entre `head` y `body` no equivale a «invisible» y «visible»: el título aparece en la pestaña y el párrafo de `details` está en `body` aunque inicialmente no se vea.

## Elegir el elemento por su significado

El **HTML semántico** expresa qué papel cumple cada parte. `nav` agrupa navegación importante; `ul` y `li` representan una lista y sus elementos; `button` representa una acción. Un texto grande no se convierte por ello en encabezado, ni un texto azul en enlace.

La estructura ayuda a la [accesibilidad](/articulos/accesibilidad-web/): por ejemplo, un lector de pantalla, que comunica el contenido mediante voz o braille, puede recorrer encabezados y regiones. Usar elementos adecuados también facilita entender y mantener el código.

Para una imagen, `img` usa `src` para indicar el archivo y `alt` para ofrecer una alternativa textual según su función. Si comunica información, la alternativa debe transmitirla. Si solo adorna o repite información ya disponible, `alt=""` evita anunciar contenido redundante. Omitir `alt` no equivale a dejarlo vacío.

## Errores comunes

- **Guardar como `index.html.txt`.** El nombre debe acabar en `.html` para que se abra como documento web.
- **Confundir que se vea con que esté bien escrito.** El navegador aplica reglas de recuperación al HTML incorrecto; no adivina tu intención. Puede construir una estructura distinta de la esperada. Un validador comprueba el marcado.
- **Anidar elementos sin respetar su contenido permitido.** Cerrar en orden no basta: un párrafo no puede contener una sección. El navegador puede cerrar el párrafo antes de lo previsto.
- **Usar solo la apariencia para representar significado.** Un encabezado o un botón necesitan el elemento correspondiente, no únicamente un tamaño o color.

## Lo esencial

- HTML marca la estructura y el significado; incluye comportamientos propios como enlaces y controles desplegables.
- Los elementos se combinan respetando sus reglas; los atributos aportan información adicional.
- El documento distingue información de la página y contenido, con encabezados que reflejan su organización.
- Una página local ya puede funcionar. Para ofrecerla a otros navegadores interviene un [servidor web](/articulos/que-es-un-servidor/).
