El **sistema hexadecimal** es una forma de escribir números que usa dieciséis símbolos: las cifras del 0 al 9 y las letras de la A a la F. Se utiliza en informática porque permite escribir valores binarios de forma mucho más corta.

Se abrevia "hex".

## Qué problema resuelve

Los ordenadores trabajan en [binario](/articulos/que-es-un-bit/), pero el binario es incómodo para las personas. El número 255 se escribe `11111111`; una dirección de memoria puede tener 64 cifras. Es fácil equivocarse al leerlo o copiarlo.

El decimal es más corto, pero no encaja con el binario: no hay forma sencilla de ver qué bits corresponden a cada cifra.

El hexadecimal resuelve las dos cosas. Es compacto y se traduce a binario cifra a cifra.

## Los dieciséis símbolos

Como hacen falta dieciséis símbolos y solo hay diez cifras, se añaden seis letras:

| Decimal | Hex | Binario |
| --- | --- | --- |
| 0 | 0 | 0000 |
| 1 | 1 | 0001 |
| 2 | 2 | 0010 |
| 9 | 9 | 1001 |
| 10 | A | 1010 |
| 11 | B | 1011 |
| 12 | C | 1100 |
| 13 | D | 1101 |
| 14 | E | 1110 |
| 15 | F | 1111 |

Funciona igual que el decimal, pero cada posición vale dieciséis veces más que la de su derecha: 1, 16, 256, 4096...

El número hexadecimal `2F` es 2 × 16 + 15 = 47.

## La clave: una cifra son cuatro bits

Dieciséis es 2 elevado a 4. Por eso cada cifra hexadecimal equivale exactamente a cuatro bits, y la conversión se hace por trozos, sin calcular nada:

| Binario | 1010 | 1111 |
| --- | --- | --- |
| Hex | A | F |

`10101111` es `AF`. Para pasar de hex a binario, se hace al revés: cada cifra se sustituye por sus cuatro bits.

Un byte, que son ocho bits, se escribe siempre con **dos cifras hexadecimales**: de `00` a `FF`, es decir, de 0 a 255. Esa correspondencia tan limpia es la razón de su éxito.

## Cómo se reconoce

Para distinguir un número hexadecimal de uno decimal se usa un prefijo. El más común en los lenguajes de programación es `0x`:

```js
console.log(0xff); // 255
console.log(0x10); // 16

console.log((255).toString(16)); // "ff"
console.log(parseInt("ff", 16)); // 255
console.log((47).toString(2)); // "101111"
```

`toString(16)` convierte un número a su escritura hexadecimal y `parseInt` con un 16 hace el camino inverso. Las letras pueden ir en mayúsculas o en minúsculas.

## Dónde lo vas a encontrar

### Colores

En [CSS](/articulos/que-es-css/), un color se escribe con seis cifras hexadecimales tras una almohadilla: dos para el rojo, dos para el verde y dos para el azul.

```js
function aRgb(color) {
	const rojo = parseInt(color.slice(1, 3), 16);
	const verde = parseInt(color.slice(3, 5), 16);
	const azul = parseInt(color.slice(5, 7), 16);

	return [rojo, verde, azul].join(", ");
}

console.log(aRgb("#ff8800")); // "255, 136, 0"
```

Cada componente va de `00` a `ff`, de nada a todo. `#ff8800` es rojo al máximo, verde a la mitad y nada de azul: un naranja. `#000000` es negro y `#ffffff`, blanco.

### Direcciones

- Las **direcciones de memoria**, como `0x7ffd4a2c`.
- Las **direcciones MAC** de la [capa de enlace](/articulos/capa-de-enlace/): `3c:22:fb:9a:41:07`.
- Las **direcciones IPv6**: `2001:0db8:85a3::8a2e:0370:7334`.

### Datos binarios

- El resultado de una [función hash](/articulos/funciones-hash/) se muestra como una cadena hexadecimal.
- Los identificadores de las confirmaciones de [Git](/articulos/control-de-versiones-con-git/).
- Los editores hexadecimales, que enseñan byte a byte el contenido de cualquier archivo.
- Los códigos de los caracteres en Unicode: `U+00F1` es la `ñ`, como explica el artículo sobre [codificación de caracteres](/articulos/codificacion-de-caracteres/).

## Otras bases

- **Octal**: base 8, con cifras del 0 al 7. Cada cifra son tres bits. Hoy se ve sobre todo en los permisos de los [sistemas de archivos](/articulos/sistema-de-archivos/) de tipo Unix.
- **Base64**: no se usa para escribir números, sino para representar datos binarios como texto corriente, por ejemplo al incrustar una imagen en un documento.

## Errores comunes

- **Leer un hexadecimal como decimal.** `10` en hex es dieciséis, no diez.
- **Olvidar la base al convertir.** `parseInt("10")` da 10; `parseInt("10", 16)` da 16.
- **Pensar que es otro tipo de número.** El valor es el mismo; cambia la forma de escribirlo.

## Lo esencial

- El hexadecimal escribe los números en base 16, con las cifras del 0 al 9 y las letras de la A a la F.
- Cada cifra equivale a cuatro bits, y un byte a dos cifras.
- Se usa porque es compacto y se traduce a binario directamente.
- Aparece en colores, direcciones, hashes e identificadores.
