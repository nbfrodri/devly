La **exactitud** (*accuracy*) es la proporción de predicciones correctas sobre el total. La **precisión** (*precision*) es la proporción de positivos reales entre los casos marcados como positivos. Al evaluar un clasificador, responden preguntas distintas.

## Para comparar

| | Exactitud | Precisión |
| --- | --- | --- |
| Pregunta | ¿Qué parte de todas las predicciones es correcta? | De lo que el modelo marca como positivo, ¿qué parte lo es? |
| Fórmula | (VP + VN) / total | VP / (VP + FP) |
| Le afecta | La frecuencia de las clases y ambos tipos de error | Los positivos detectados y las falsas alarmas; también la frecuencia de la clase |
| Útil cuando | Importa el porcentaje global de aciertos, con costes comparables | Importa la proporción de alarmas correctas |

VP son verdaderos positivos; VN, verdaderos negativos; FP, falsos positivos. Lo explica la [matriz de confusión](/articulos/como-se-evalua-un-modelo-de-clasificacion/).

## Por qué la exactitud engaña

Un filtro de spam con 1000 correos, de los que solo 10 son spam:

```js
const exactitud = (vp, fp, fn, vn) => (vp + vn) / (vp + fp + fn + vn);
const precision = (vp, fp) => vp / (vp + fp);
const exhaustividad = (vp, fn) => vp / (vp + fn);

// Always predict the negative class.
console.log(exactitud(0, 0, 10, 990)); // 0.99

// Compare another detector on the same messages.
console.log(exactitud(8, 12, 2, 978), precision(8, 12), exhaustividad(8, 2)); // 0.986 0.4 0.8
```

La referencia que no detecta nada tiene un 99 % de exactitud, más que el segundo detector. Ese porcentaje es correcto, pero no responde cuántos mensajes de spam encuentra. El equilibrio de clases tampoco basta para elegir exactitud: importan los costes de los errores y la pregunta que se quiere responder.

El segundo detector atrapa 8 de los 10 spam (**exhaustividad** del 80 %), pero de los 20 correos que marca, solo 8 lo eran: **precisión** del 40 %. Esa cifra describe sus falsas alarmas; decidir si es útil exige valorar las consecuencias. La precisión de la referencia no está definida por la fórmula, porque no marca ningún positivo y divide cero entre cero. No debe presentarse como precisión perfecta.

## Precisión y exhaustividad

Para puntuaciones fijas, subir el umbral reduce o mantiene los casos marcados y no aumenta la exhaustividad. La precisión puede subir o bajar: si la puntuación más alta corresponde a un negativo, quedarse solo con ella empeora la proporción de aciertos. El artículo de [evaluación de clasificadores](/articulos/como-se-evalua-un-modelo-de-clasificacion/) recorre ese contraejemplo. Qué priorizar depende del coste de cada error:

- **Prima la precisión** cuando una falsa alarma es cara: bloquear una cuenta legítima.
- **Prima la exhaustividad** cuando se escapa algo grave: no detectar una enfermedad.

La misma trampa de las clases raras explica el [teorema de Bayes](/articulos/teorema-de-bayes/).

## En física, otra cosa

En medición, exactitud es lo cerca que están las medidas del valor real, y precisión, lo parecidas que son entre sí. Es un uso distinto de las mismas palabras.

## Lo esencial

- La exactitud es la proporción de aciertos sobre el total.
- La precisión es la proporción de positivos reales entre los que el modelo marca como positivos.
- Con clases desequilibradas, una exactitud alta puede esconder un modelo inútil.
- Se elige entre precisión y exhaustividad según el coste de cada tipo de error.
