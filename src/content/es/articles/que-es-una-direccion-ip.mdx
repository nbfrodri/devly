Una **dirección IP** es una dirección numérica usada para dirigir datos hacia una **interfaz de red**, la conexión de un equipo con una red. Un portátil puede tener una interfaz wifi y otra de cable, con direcciones distintas. Una interfaz también puede tener varias IP.

IP son las siglas de *Internet Protocol*: un [protocolo de red](/articulos/que-es-un-protocolo-de-red/) que define direcciones y reglas para transportar datos entre redes. La dirección ayuda a localizar un destino, como una dirección postal; no identifica permanentemente a su dueño. Su lugar entre otros protocolos se explica en los [modelos OSI y TCP/IP](/articulos/modelos-osi-y-tcp-ip/).

## Qué problema resuelve

Cuando abres una página web, tu dispositivo y el [servidor](/articulos/que-es-un-servidor/) que la ofrece intercambian datos. IP los transporta en unidades llamadas **paquetes**: cada una contiene datos y una cabecera con información para tratarlos. Un mensaje grande puede necesitar muchos paquetes.

Cada paquete lleva una IP de origen y otra de destino. Los **routers**, equipos que conectan redes, consultan la de destino para elegir el siguiente tramo. IP por sí solo no reenvía lo perdido ni ordena lo recibido. Algunos intercambios añaden [TCP](/articulos/tcp-y-udp/), que detecta pérdidas y retransmite para ofrecer un flujo ordenado de datos; la conexión también puede fallar.

## Qué aspecto tiene

**IPv4** escribe la dirección como cuatro números separados por puntos, cada uno entre 0 y 255:

```
192.168.1.20
```

Ese rango no es casual. Cada número ocupa un [byte](/articulos/que-es-un-byte/), y con sus 8 [bits](/articulos/que-es-un-bit/) se representan 256 valores, del 0 al 255. Cuatro bytes son 32 bits.

```js
console.log(2 ** 32); // 4294967296
```

Son unos 4300 millones de valores posibles; algunos están reservados para usos especiales. Asignar una dirección pública diferente a cada conexión consume ese espacio limitado.

### IPv6

Para ampliar el espacio se creó [**IPv6**](/articulos/ipv4-frente-a-ipv6/), que usa 128 bits. Su forma completa tiene ocho grupos de cifras [hexadecimales](/articulos/sistema-hexadecimal/) separados por dos puntos:

```
2001:0db8:85a3:0000:0000:8a2e:0370:7334
```

Sus `2^128` valores permiten un espacio muchísimo mayor. No hacen innecesaria la planificación de direcciones. Las dos versiones tienen formatos distintos; una conexión necesita soporte compatible o un mecanismo de traducción.

## Públicas y privadas

No todas las direcciones sirven para lo mismo.

Una **IP pública** pertenece al espacio destinado a comunicación global. Tu proveedor puede asignarte una para salir a internet, pero tenerla no garantiza que otro equipo pueda conectarse: también hacen falta una ruta, un programa que atienda y reglas que permitan el tráfico.

Una **IP privada** puede usarse dentro de redes administradas de forma privada, incluso entre varias sedes, pero no se enruta directamente por la internet pública. IPv4 reserva tres rangos que distintas organizaciones pueden reutilizar:

| Rango | Uso habitual |
| --- | --- |
| `10.0.0.0` a `10.255.255.255` | Redes grandes |
| `172.16.0.0` a `172.31.255.255` | Redes medianas |
| `192.168.0.0` a `192.168.255.255` | Redes domésticas |

Por eso tu ordenador y el de otra persona en otra ciudad pueden tener los dos la dirección `192.168.1.20` sin conflicto: cada uno está en su propia red.

### Cómo sale a internet una IP privada

En una configuración doméstica habitual, el router tiene una dirección privada hacia dentro y una pública hacia fuera. Al salir un paquete, sustituye su dirección de origen y normalmente su puerto; guarda la correspondencia para devolver la respuesta al equipo correcto. Es una forma de [**NAT**](/articulos/que-es-nat/), traducción de direcciones.

Así varios dispositivos pueden compartir una IP pública. El operador también puede aplicar NAT: en ese caso el router doméstico no recibe necesariamente una pública propia. Por eso una IP observada por una web no demuestra qué persona o dispositivo hizo la petición.

## Quién asigna la dirección

Normalmente no la configuras tú. Al conectarte a una red, tu dispositivo pide una dirección y el router le presta una libre durante un tiempo. El mecanismo se llama **[DHCP](/articulos/que-es-dhcp/)**. Por eso la IP privada de tu móvil puede cambiar de un día para otro.

Una asignación **dinámica** puede cambiar al renovarse o cambiar de red. Una dirección **estática** se configura para mantenerse mientras no se modifique esa configuración. Un servidor puede usar una IP dinámica si su nombre o el punto de entrada se actualiza; no necesita por definición una dirección fija.

## Una dirección especial

`127.0.0.1` es una dirección de **bucle local**: el tráfico vuelve al propio equipo, sin salir a la red. Pertenece al bloque IPv4 reservado `127.0.0.0/8`. El nombre `localhost` suele resolver a ella y a `::1`, su equivalente IPv6. Sirve, por ejemplo, para probar una web en tu ordenador.

## Direcciones y nombres

Las personas no recuerdan números, así que escribimos nombres como `wikipedia.org`. Antes de conectarse, tu dispositivo consulta un servicio llamado [**DNS**](/articulos/que-es-dns/) que traduce ese nombre a la dirección IP correspondiente. El nombre es para ti; la IP es lo que usa la red.

El tamaño de un paquete también está condicionado por la [MTU](/articulos/que-es-una-mtu/) de los enlaces del camino; poder enviarlo por el primer tramo no garantiza que quepa en los siguientes.

## Lo esencial

- Una IP permite dirigir paquetes hacia una interfaz; un equipo puede tener varias.
- IPv4 usa 32 bits y se escribe como cuatro números de 0 a 255; IPv6 usa 128 bits.
- Las IP privadas se reutilizan en redes distintas y no se enrutan directamente por internet; NAT puede permitir su salida.
- `127.0.0.1` es tu propio dispositivo.
