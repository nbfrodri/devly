Una **dirección MAC** es una dirección de la [capa de enlace](/articulos/capa-de-enlace/), usada para entregar tramas en redes como Ethernet y wifi. En estas tecnologías tiene 48 [bits](/articulos/que-es-un-bit/) y suele escribirse como seis pares [hexadecimales](/articulos/sistema-hexadecimal/): `00:1A:2B:3C:4D:5E`. Una interfaz de una [tarjeta de red](/articulos/tarjeta-de-red/) puede usar una MAC asignada por el fabricante o configurada localmente.

MAC son las siglas de *media access control*, control de acceso al medio.

## Su estructura

```js
const mac = "00:1A:2B:3C:4D:5E";
const partes = mac.split(":");

console.log(partes.length); // 6
console.log(partes.slice(0, 3).join(":")); // "00:1A:2B"
console.log(2 ** 48); // 281474976710656
```

En una asignación global del tipo MA-L, los primeros tres bytes corresponden al bloque de una organización; esta asigna los restantes. IEEE también ofrece bloques de otros tamaños. Una MAC administrada localmente no permite deducir el fabricante por esos tres bytes.

## Para qué sirve

Trabaja en la [capa de enlace](/articulos/capa-de-enlace/). Cuando un equipo envía algo a otro de su misma red, el conmutador mira la dirección MAC de destino para saber por qué cable sacarlo, o el punto de acceso, a qué dispositivo enviarlo.

Para obtener la MAC del siguiente destinatario en IPv4 sobre Ethernet se usa [ARP](/articulos/que-es-arp/). IPv6 emplea descubrimiento de vecinos.

## MAC e IP

| | Dirección MAC | Dirección IP |
| --- | --- | --- |
| Uso | Entregar tramas en el ámbito de enlace | Dirigir paquetes entre redes |
| Ámbito | Enlace o red local | Depende del tipo de dirección y las rutas |
| Capa | Enlace | Red |
| Puede cambiar | Sí: configuración, privacidad | Sí: configuración, cambio de red |

Un router no arrastra la cabecera Ethernet original hasta el destino remoto. Crea el envoltorio adecuado para el siguiente enlace. Las IP pueden conservarse durante el recorrido, pero una traducción [NAT](/articulos/que-es-nat/) puede modificarlas.

## Privacidad

Reutilizar una MAC facilita relacionar conexiones del mismo dispositivo. Algunos sistemas usan **direcciones privadas**, que pueden variar según la red o con el tiempo. Su comportamiento depende del sistema y la configuración. Una MAC tampoco es una prueba de identidad: puede copiarse o modificarse.

## Con qué no confundirla

No tiene relación con los ordenadores Mac de Apple: es una coincidencia de siglas.
