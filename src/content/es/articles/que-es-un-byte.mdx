Un **byte** es un grupo de **8 [bits](/articulos/que-es-un-bit/)**. Es la unidad básica con la que se mide la memoria, el almacenamiento y el tamaño de los archivos. Se abrevia con **B** mayúscula.

## Cuánto cabe en un byte

Con 8 bits hay 2⁸ combinaciones posibles:

```js
console.log(2 ** 8); // 256
console.log((255).toString(2)); // "11111111"
console.log((255).toString(16)); // "ff"
```

Un byte interpretado como entero sin signo representa de 0 a 255. También puede contener un código de carácter o una parte de una codificación de varios bytes. Por eso los bytes se escriben a menudo con dos cifras [hexadecimales](/articulos/sistema-hexadecimal/), de `00` a `ff`.

## Un carácter, un byte… no siempre

ASCII define códigos de siete bits, habitualmente almacenados en bytes de ocho. En UTF-8, un carácter como `ñ` o `€` necesita varios bytes; una secuencia visible puede combinar además varios códigos, como explica [codificación de caracteres](/articulos/codificacion-de-caracteres/). Este ejemplo usa `Buffer` de **Node.js**, cuya codificación predeterminada para texto es UTF-8:

```js
console.log(Buffer.from("n").length); // 1
console.log(Buffer.from("ñ").length); // 2
console.log(Buffer.from("€").length); // 3
```

## Bits y bytes

La confusión más frecuente:

- Los **archivos** y la memoria se miden en **bytes**: B, kB, MB.
- La **velocidad** de una conexión, en **bits** por segundo: bit/s, kbit/s, Mbit/s; también verás Mb/s.

Una conexión de 100 Mb/s transfiere como mucho unos 12,5 MB por segundo. El prefijo kilo significa 1000; para 1024 existe kibi, aunque persiste el uso ambiguo de «kilo», como explica [kilobyte, 1000 o 1024](/articulos/kilobyte-1000-o-1024/).

## Una unidad definida

En las unidades actuales recogidas por el NIST, un byte equivale a 2³ bits: ocho. No es una deducción a partir del archivo, sino la unidad con la que se cuenta. Tampoco significa que cada dato ocupe un byte: una imagen, un entero o un texto pueden usar muchos, según su representación.
