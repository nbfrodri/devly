Un **intervalo de confianza** es un rango calculado a partir de una muestra mediante un procedimiento diseñado para cubrir el parámetro buscado en una proporción determinada de muestras repetidas. Esa cobertura depende de que se cumplan sus supuestos. Sirve cuando no podemos medir una población entera y queremos expresar la incertidumbre de una estimación, como su media.

"El tiempo medio de carga es de 50 ms" dice menos que "está entre 48,6 y 51,4 ms, con un 95 % de confianza".

## Cómo se calcula

Para la media, un procedimiento habitual usa la media de la muestra más y menos un **margen de error**. En este ejemplo suponemos diez observaciones independientes de una población normal cuya desviación desconocemos. El margen crece con la dispersión estimada y decrece con el tamaño de la muestra:

```js
const muestra = [52, 48, 50, 51, 49, 53, 47, 50, 52, 48];
const n = muestra.length;

const media = muestra.reduce((a, b) => a + b) / n;
const desviacion = Math.sqrt(muestra.reduce((a, x) => a + (x - media) ** 2, 0) / (n - 1));
const errorEstandar = desviacion / Math.sqrt(n);

// Valor de la t de Student para un 95 % con 9 grados de libertad.
const t = 2.262;
const margen = t * errorEstandar;

console.log(media, desviacion); // 50 2
console.log(`${(media - margen).toFixed(2)} a ${(media + margen).toFixed(2)}`); // "48.57 a 51.43"
```

- La **desviación típica** mide cuánto varían los datos, como explica [media, mediana y desviación](/articulos/media-mediana-y-desviacion/).
- El **error estándar** describe cuánto varía la media entre muestras. Aquí lo estimamos dividiendo la desviación muestral entre `√n`: `2 / √10 ≈ 0,632` ms.
- Como estimamos la desviación poblacional a partir de los datos, usamos la **t de Student** con `n - 1 = 9` grados de libertad. El factor 2,262 da un margen de unos 1,43 ms. No se elige Student solo por tener pocos datos: también depende de qué desviación conocemos y del modelo.
- Con observaciones normales y desviación poblacional conocida, se usa el factor normal 1,96. Con muestras grandes puede haber aproximaciones justificadas por el límite central; diez observaciones muy asimétricas no quedan justificadas por ese teorema.

Manteniendo dispersión y factor crítico, reducir el margen a la mitad requiere **cuatro veces** más muestra por la raíz cuadrada. Con Student es una aproximación: su factor también cambia al aumentar los grados de libertad.

## Qué significa el 95 %

Es la parte que más se malinterpreta. El manual de estadística del NIST lo explica así: si se tomaran muchas muestras de la misma población y se calculara un intervalo con cada una, aproximadamente el 95 % de esos intervalos contendrían el valor real.

Podemos ilustrar la cobertura con 1000 muestras de 30 observaciones normales, de media 100 y desviación **conocida** 15. Por eso esta simulación usa 1,96, a diferencia del ejemplo anterior. El generador con semilla fija permite repetir el experimento; la transformación `normal` produce observaciones de una normal estándar a partir de pares uniformes:

```js
function generador(semilla) {
	let a = semilla;
	return () => {
		a |= 0;
		a = (a + 0x6d2b79f5) | 0;
		let t = Math.imul(a ^ (a >>> 15), 1 | a);
		t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
		return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
	};
}
const azar = generador(42);
const normal = () => Math.sqrt(-2 * Math.log(1 - azar())) * Math.cos(2 * Math.PI * azar());

let aciertos = 0;
for (let k = 0; k < 1000; k++) {
	let suma = 0;
	for (let i = 0; i < 30; i++) suma += 100 + 15 * normal();
	const media = suma / 30;
	const errorEstandar = 15 / Math.sqrt(30);
	if (Math.abs(media - 100) <= 1.96 * errorEstandar) aciertos++;
}

console.log(aciertos); // 946
```

946 de 1000 intervalos contienen el 100: cerca del 95 % esperado. Con [números pseudoaleatorios](/articulos/numeros-aleatorios-y-pseudoaleatorios/) y una semilla fija, el resultado se puede repetir.

Lo que **no** significa: que haya un 95 % de probabilidad de que el valor real esté en *este* intervalo concreto. El valor real es fijo; lo aleatorio es el intervalo. Es una distinción sutil, pero es la que separa este enfoque del [bayesiano](/articulos/teorema-de-bayes/).

## Errores habituales

- **Dar solo la media**, sin intervalo, como si fuera exacta.
- **Muestras sesgadas**: el intervalo no corrige una selección inadecuada. Si solo se mide a los usuarios más activos, puede quedar estrecho alrededor de una estimación que no representa al conjunto.
- **Comparar intervalos a ojo**: que dos intervalos se solapen no significa necesariamente que no haya diferencia. Para eso está el [contraste de hipótesis](/articulos/contraste-de-hipotesis-y-valor-p/).

## Lo esencial

- Un intervalo de confianza expresa incertidumbre mediante un procedimiento de cobertura definido.
- El intervalo para la media usado aquí suma y resta un margen que depende de la dispersión y del tamaño de la muestra.
- El 95 % es la cobertura del procedimiento bajo sus supuestos; una serie finita de intervalos no tiene por qué acertar exactamente ese porcentaje.
- No corrige una muestra sesgada: solo mide el error debido al azar.
