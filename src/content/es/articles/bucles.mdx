Un **bucle** es una instrucción que repite un bloque de código varias veces. Evita escribir lo mismo una y otra vez y permite trabajar con cantidades que no conoces de antemano.

## Por qué hacen falta

Mostrar los números del 1 al 3 se puede hacer con tres líneas. Mostrar del 1 al 1000 no. Y si la cantidad depende de algo que solo se sabe mientras el programa funciona, como cuántos productos hay en un carrito, no hay forma de escribirlo línea a línea. Un bucle resuelve los dos casos: describes una vuelta y dices cuándo parar.

## Repetir mientras algo sea cierto

`while` significa "mientras". Repite el bloque mientras la [condición](/articulos/condicionales/) sea verdadera.

```js
let contador = 1;

while (contador <= 3) {
	console.log(contador);
	contador = contador + 1;
}
// Muestra 1, 2 y 3
```

Conviene seguirlo paso a paso:

1. `contador` vale 1. ¿Es menor o igual que 3? Sí. Muestra 1 y pasa a valer 2.
2. ¿2 es menor o igual que 3? Sí. Muestra 2 y pasa a valer 3.
3. ¿3 es menor o igual que 3? Sí. Muestra 3 y pasa a valer 4.
4. ¿4 es menor o igual que 3? No. El bucle termina.

La condición se comprueba **antes** de cada vuelta. Si fuera falsa desde el principio, el bloque no se ejecutaría ni una vez.

### Bucles infinitos

La línea `contador = contador + 1` es imprescindible. Sin ella `contador` valdría siempre 1, la condición nunca dejaría de cumplirse y el programa repetiría el bloque sin parar. Eso es un **bucle infinito**, y normalmente deja el programa bloqueado.

Para que este bucle termine, el contador debe avanzar hacia el límite. En general, necesitas una condición de salida alcanzable: puede depender de los datos recorridos o de una salida explícita con `break`, que veremos más abajo. No todos los bucles terminan porque cambie una variable en cada vuelta.

## Repetir un número de veces

Cuando sabes cuántas vueltas quieres, `for` reúne en una línea las tres piezas que en `while` estaban repartidas:

```js
for (let i = 1; i <= 3; i++) {
	console.log(i);
}
// Muestra 1, 2 y 3
```

Entre los paréntesis hay tres partes separadas por punto y coma:

- `let i = 1`: el **inicio**. Se ejecuta una sola vez, antes de empezar.
- `i <= 3`: la **condición**. Se comprueba antes de cada vuelta.
- `i++`: el **paso**. Se ejecuta al final de cada vuelta. Es una forma corta de escribir `i = i + 1`.

La variable se suele llamar `i`, de "índice". Es una convención.

## Recorrer una lista

El uso más frecuente de un bucle es hacer algo con cada elemento de una lista, o [array](/articulos/arrays/). Para eso existe `for...of`, que no necesita contador:

```js
const frutas = ["manzana", "pera", "uva"];

for (const fruta of frutas) {
	console.log(fruta);
}
// Muestra manzana, pera y uva
```

Los corchetes crean una lista de valores separados por comas. En cada vuelta se crea una variable `fruta` con el siguiente elemento; por eso se puede usar `const` sin reasignar la variable de la vuelta anterior. El bucle termina cuando se acaba la lista, salvo que lo interrumpas antes.

## Acumular un resultado

Un patrón muy habitual es crear una variable antes del bucle e ir actualizándola en cada vuelta:

```js
const precios = [10, 25, 5];
let total = 0;

for (const precio of precios) {
	total = total + precio;
}

console.log(total); // 40
```

`total` se declara fuera del bucle. Si se declarase dentro, volvería a valer 0 en cada vuelta.

| Vuelta | `precio` | `total` antes | `total` después |
| --- | --- | --- | --- |
| 1 | 10 | 0 | 10 |
| 2 | 25 | 10 | 35 |
| 3 | 5 | 35 | 40 |

Si la lista estuviera vacía, no habría ninguna vuelta y el total seguiría siendo 0. Elegir el valor inicial forma parte del algoritmo: para sumar se empieza en 0; para multiplicar valores, normalmente en 1.

## Salir antes o saltarse una vuelta

- `break` termina el bucle en ese momento.
- `continue` abandona la vuelta actual y pasa a la siguiente.

```js
for (let i = 1; i <= 5; i++) {
	if (i === 3) {
		continue;
	}
	if (i === 5) {
		break;
	}
	console.log(i);
}
// Muestra 1, 2 y 4
```

## Errores comunes

- **Olvidar el paso** en un `while` y crear un bucle infinito.
- **Pasarse o quedarse corto por uno.** `i < 5` empezando en 0 da cinco vueltas (0, 1, 2, 3, 4); `i <= 5` da seis. Es tan frecuente que tiene nombre propio: error *off-by-one*.
- **Declarar dentro del bucle** la variable que acumula el resultado.

## Lo esencial

- Un bucle repite un bloque mientras se cumpla una condición.
- `while` sirve cuando no sabes cuántas vueltas hacen falta; `for`, cuando lo sabes; `for...of`, para recorrer una lista.
- Un bucle que deba terminar necesita una condición de salida alcanzable.
