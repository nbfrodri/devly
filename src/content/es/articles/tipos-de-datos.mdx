Un **tipo de dato** es la clase a la que pertenece un valor: un número, un texto, un sí o no. El tipo determina qué puedes hacer con ese valor. Puedes dividir dos números, pero dividir dos frases no significa nada.

## Por qué existen

Para el ordenador todo son [bits](/articulos/que-es-un-bit/). Los mismos ceros y unos pueden ser un número, una letra o un color según cómo se interpreten. El tipo es esa interpretación: le dice al lenguaje qué representa el valor y qué operaciones tienen sentido con él.

En algunos lenguajes los tipos se comprueban antes de ejecutar y en otros durante la ejecución: es la diferencia entre [tipado estático y dinámico](/articulos/tipado-estatico-y-dinamico/).

## Los tipos básicos

JavaScript tiene varios tipos. Estos cinco son los que aparecen desde el primer día:

| Tipo | Qué representa | Ejemplos |
| --- | --- | --- |
| `number` | Un número, con o sin decimales | `30`, `3.14`, `-5` |
| `string` | Un texto | `"Ana"`, `"Hola, mundo"` |
| `boolean` | Verdadero o falso | `true`, `false` |
| `undefined` | Todavía no tiene valor | `undefined` |
| `null` | No tiene valor, a propósito | `null` |

El operador `typeof` devuelve el tipo de un valor:

```js
console.log(typeof 30); // "number"
console.log(typeof "Ana"); // "string"
console.log(typeof true); // "boolean"

let pendiente;
console.log(typeof pendiente); // "undefined"
```

Una variable declarada sin valor vale `undefined`. En cambio `null` lo escribes tú cuando quieres dejar claro que algo está vacío.

## Números

Los números se escriben tal cual, con punto para los decimales. Los decimales guardan una sorpresa: [0,1 + 0,2 no da exactamente 0,3](/articulos/por-que-0-1-mas-0-2-no-da-0-3/). Admiten las operaciones habituales:

```js
console.log(7 + 2); // 9
console.log(7 - 2); // 5
console.log(7 * 2); // 14
console.log(7 / 2); // 3.5
console.log(7 % 2); // 1
```

`%` es el resto de la división: 7 entre 2 da 3 y sobra 1. Se usa mucho para saber si un número es par, porque el resto de dividir un número par entre 2 es 0.

## Textos

Un texto, o *string*, va siempre entre comillas. Sin ellas el lenguaje lo interpretaría como el nombre de una variable.

Con textos, `+` no suma: une uno detrás de otro.

```js
const nombre = "Ana";
console.log("Hola, " + nombre); // "Hola, Ana"
console.log(nombre.length); // 3
```

`.length` cuenta unidades de código UTF-16, la representación que usa JavaScript para los textos. Para `"Ana"` coincide con las tres letras, pero algunos símbolos, como `"😀"`, ocupan dos unidades. Por eso no siempre coincide con el número de caracteres que ves; la diferencia se desarrolla en [codificación de caracteres](/articulos/codificacion-de-caracteres/).

Hay una forma más cómoda de mezclar texto y variables: las comillas invertidas. Dentro de ellas, lo que pongas entre `${` y `}` se sustituye por su valor.

```js
const nombre = "Ana";
const edad = 30;
console.log(`${nombre} tiene ${edad} años`); // "Ana tiene 30 años"
```

## Booleanos

Un booleano solo puede ser `true` o `false`. Casi nunca lo escribes a mano: es el resultado de una comparación.

```js
console.log(5 > 3); // true
console.log(5 === 3); // false
```

Son la base de las decisiones de un programa, que se explican en [condicionales](/articulos/condicionales/).

Cuando una variable solo puede tomar unos pocos valores con nombre, como los estados de un pedido, se usa un [enum](/articulos/que-es-un-enum/).

## Cuando los tipos se mezclan

Las comillas cambian el tipo. `2` es un número y `"2"` es un texto que contiene el carácter 2.

```js
console.log(2 + 2); // 4
console.log("2" + "2"); // "22"
console.log("2" + 2); // "22"
```

En la tercera línea JavaScript encuentra un texto y un número, convierte el número en texto y los une. Esta conversión automática puede producir errores: por ejemplo, la propiedad `value` de un campo de formulario devuelve texto, incluso si el campo permite introducir números.

Para evitar sorpresas, convierte tú el valor:

```js
console.log(Number("2") + 2); // 4
console.log(String(2) + "2"); // "22"
```

## Errores comunes

- **Olvidar las comillas de un texto.** `let nombre = Ana` busca una variable llamada `Ana` y falla porque no existe.
- **Sumar un número que en realidad es un texto.** Si el resultado sale "pegado" en lugar de sumado, comprueba el tipo con `typeof`.
- **Confundir `undefined` con un error.** `undefined` es un valor normal: significa que todavía no hay nada.

El [fallo de Ariane 5](/articulos/ariane-5-y-las-suposiciones-del-software/) recuerda por qué reutilizar código exige revisar los rangos y supuestos del nuevo entorno.

## Lo esencial

- El tipo dice qué clase de valor tienes y qué operaciones admite.
- Los básicos son `number`, `string`, `boolean`, `undefined` y `null`.
- `typeof` te dice el tipo; `Number()` y `String()` convierten entre tipos.
- El mismo operador puede hacer cosas distintas según el tipo: `+` suma números y une textos.
