Un **archivo**, o fichero, permite organizar y recuperar datos como una unidad. Aquí hablamos de un **archivo regular**: una secuencia de [bytes](/articulos/que-es-un-byte/) que puede contener texto, una imagen o un programa. Su formato indica cómo interpretar el contenido.

Un nombre dentro de un **directorio**, o carpeta, permite localizarlo. Guardarlo en una SSD puede conservarlo al apagar, pero no garantiza conservación permanente; también existen sistemas de archivos temporales en RAM.

## Contenido, nombres y metadatos

Además del contenido están los **metadatos**: tamaño, fechas, propietario y [permisos](/articulos/permisos-y-usuarios/) de acceso. Según el sistema, varios nombres pueden referirse al mismo archivo. El nombre y los bytes no son la misma cosa.

El **[sistema de archivos](/articulos/sistema-de-archivos/)** organiza nombres, metadatos y contenido, y lleva la ubicación de los datos. [FAT y NTFS](/articulos/fat-y-ntfs/) son ejemplos de formatos con reglas distintas.

## Crear, leer y eliminar

Los programas utilizan bibliotecas que solicitan servicios del sistema operativo mediante **[llamadas al sistema](/articulos/llamadas-al-sistema/)**. Este ejemplo se ejecuta con Node.js, guardado en un archivo `.mjs`; crea su propio directorio temporal:

```js
import { existsSync, mkdtempSync, readFileSync, rmdirSync, statSync, unlinkSync, writeFileSync } from "node:fs";
import { tmpdir } from "node:os";
import { join } from "node:path";

const directorio = mkdtempSync(join(tmpdir(), "devly-archivo-"));
const ruta = join(directorio, "saludo.txt");

try {
	writeFileSync(ruta, "hola", { encoding: "utf8", flag: "wx" });
	console.log(readFileSync(ruta, "utf8")); // "hola"
	console.log(statSync(ruta).size); // 4
} finally {
	if (existsSync(ruta)) unlinkSync(ruta);
	rmdirSync(directorio);
}
```

El contenido ocupa 4 bytes en UTF-8, uno por letra; el espacio asignado en disco puede ser mayor. Las funciones elegidas abren y cierran el archivo internamente. `wx` crea un archivo nuevo y falla si ya existe. `finally` intenta retirar el ejemplo al terminar, incluso si una operación falla, sin reutilizar una ruta fija de otro programa.

## La extensión no convierte el contenido

La parte final del nombre, como `.txt` o `.jpg`, es una convención que ayuda a elegir un programa. Renombrar una foto como `.txt` no la convierte en texto. Algunos formatos tienen bytes iniciales característicos, pero reconocerlos no valida todo el contenido: lo explica [qué es un binario](/articulos/que-es-un-binario/).

En sistemas tipo Unix, también hay interfaces similares a archivos para dispositivos o información de procesos. Eso no las convierte en archivos regulares almacenados en disco. La [jerarquía de directorios de Linux](/articulos/jerarquia-de-directorios-de-linux/) desarrolla esa organización.
