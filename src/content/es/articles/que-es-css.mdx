**CSS** (*Cascading Style Sheets*, hojas de estilo en cascada) define la presentación de una página web: colores, tipos de letra, espacios y disposición del contenido. Aplica reglas a los elementos descritos con [HTML](/articulos/que-es-html/).

## Qué problema resuelve

Si el horario de una biblioteca aparece en veinte páginas, repetir su presentación en cada fragmento de contenido complica cualquier cambio. Una hoja de estilos compartida permite cambiar el aspecto de los elementos que selecciona sin reescribir sus textos.

La separación también permite adaptar la misma información a distintas pantallas o a la impresión. El significado de un encabezado sigue en HTML aunque CSS cambie su tamaño.

## Una regla selecciona y declara

```css
p {
	color: darkblue;
	font-size: 18px;
}
```

`p` es el **selector**: elige los párrafos. Cada **declaración** asigna un valor a una **propiedad**, la característica que queremos modificar. `color: darkblue` cambia el color del texto; `font-size: 18px` fija el tamaño de letra en 18 **píxeles CSS**, unidades de medida de la página que no equivalen necesariamente a píxeles físicos de la pantalla.

| Selector | Selecciona |
| --- | --- |
| `p` | Elementos de tipo párrafo |
| `.aviso` | Elementos cuya lista de clases incluye `aviso` |
| `#horario` | El elemento con `id="horario"` |
| `nav a` | Enlaces contenidos en un elemento `nav` |

Una **clase** es una etiqueta reutilizable del atributo `class`. Un elemento puede tener varias, separadas por espacios; un `id` identifica un único elemento en el documento.

## Un ejemplo completo con dos archivos

Crea una carpeta y guarda este contenido como `index.html`:

```html
<!doctype html>
<html lang="es">
	<head>
		<meta charset="utf-8">
		<meta name="viewport" content="width=device-width, initial-scale=1">
		<title>Horario de la biblioteca</title>
		<link rel="stylesheet" href="estilos.css">
	</head>
	<body>
		<main>
			<h1>Biblioteca del barrio</h1>
			<p>De lunes a viernes, de 9:00 a 18:00.</p>
			<p class="aviso">El sábado cerramos.</p>
		</main>
	</body>
</html>
```

En la misma carpeta, guarda `estilos.css` con estas reglas. Después abre `index.html` en el navegador:

```css
body {
	color: navy;
	font-family: sans-serif;
	margin: 16px;
}

.aviso {
	color: darkred;
	background-color: lightyellow;
	width: 200px;
	padding: 20px;
	border: 2px solid darkred;
}

p {
	color: black;
}

.aviso {
	color: maroon;
}

@media (max-width: 600px) {
	.aviso {
		box-sizing: border-box;
		width: 100%;
	}
}
```

`link` carga la hoja indicada por `href`. También se puede escribir CSS dentro de `style` en `head`, o usar el atributo `style` de un elemento; el archivo externo facilita compartir reglas. El navegador ya tiene estilos predeterminados: una página sin CSS propio no aparece sin formato.

## Seguir la cascada

La **cascada** decide qué declaración se aplica a cada propiedad cuando coinciden varias. No gana siempre la última ni la más específica: antes cuentan factores como el origen —navegador, usuario o página—, la prioridad `!important` y las **capas de cascada**, grupos de reglas con un orden declarado.

En este ejemplo todas las reglas son de la página, sin `!important`, capas, estilos en atributos ni animaciones. En esas condiciones comparamos la **especificidad**, el peso del selector, y después su orden:

1. El párrafo normal coincide con `p`: su texto queda negro.
2. El aviso coincide con `p` y con `.aviso`. El selector de clase pesa más que el de tipo, aunque `p` aparezca después.
3. Las dos reglas `.aviso` tienen igual especificidad. Para `color` gana la última: el aviso queda `maroon`, granate.
4. La segunda regla no menciona `background-color`. Por eso conserva el fondo `lightyellow` de la primera: la decisión se toma **propiedad por propiedad**, no descartando reglas enteras.

Para los selectores simples de la tabla, un identificador pesa más que una clase, y una clase más que un tipo. Los selectores combinados requieren comparar sus componentes; «más largo» no significa automáticamente «más específico».

## La herencia cubre lo que no se declara

La **herencia** permite que algunas propiedades tomen el valor del elemento que las contiene. En el ejemplo, el encabezado hereda el color `navy` de `body`; los párrafos tienen su propio color y no heredan ese valor. La tipografía sí les llega del contenedor.

No todas las propiedades se heredan: el borde del aviso no aparece alrededor de cada elemento interior. Una declaración que se aplica directamente al elemento tampoco compite por especificidad con un valor heredado: primero se resuelve el valor propio.

## Medir la caja y adaptarla

Una **caja** de contenido tiene relleno interior (`padding`), borde (`border`) y margen exterior (`margin`). En una ventana de más de 600 píxeles, el aviso usa el modelo inicial `content-box`: `width` mide el contenido. Su ancho hasta el borde es `200 + 20 + 20 + 2 + 2 = 244` píxeles. El margen queda fuera de esa cuenta.

Una **consulta de medios**, `@media`, aplica reglas si se cumple una condición. A 600 píxeles de ancho o menos entra la regla del ejemplo: `width: 100%` ocupa el ancho disponible del contenedor y `border-box` incluye relleno y borde dentro de ese ancho. Con una ventana de 390 píxeles y los márgenes laterales de 16, el aviso mide 358 píxeles. El texto sigue presente; no desaparece una función para hacerla caber.

Los elementos tampoco se apilan todos por defecto: los párrafos suelen formar bloques separados; los enlaces dentro de un párrafo siguen en su línea. CSS puede cambiar esta disposición. **Flexbox** distribuye elementos sobre un eje principal y **Grid** organiza filas y columnas; el [diseño adaptable](/articulos/diseno-adaptable/) desarrolla cómo combinarlos según el espacio disponible.

## Errores comunes

- **Añadir reglas sin comprobar qué coincide.** Las herramientas de desarrollo del navegador muestran los estilos aplicados y los que otra declaración ha superado.
- **Corregir cada conflicto con `!important`.** Cambia la prioridad y dificulta entender las siguientes modificaciones.
- **Esperar que el margen forme parte de `width`.** Ni siquiera `border-box` lo incluye.
- **Cambiar CSS y no ver nada.** Comprueba que guardaste ambos archivos, que `href` coincide con el nombre real y que recargaste la página.

## Lo esencial

- Una regla selecciona elementos y asigna valores a propiedades.
- La cascada resuelve cada propiedad; especificidad y orden actúan dentro de sus condiciones.
- Algunas propiedades se heredan; las cajas tienen contenido, relleno, borde y margen.
- El mismo HTML puede adaptarse al espacio disponible sin perder información.
